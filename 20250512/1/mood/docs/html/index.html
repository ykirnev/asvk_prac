Welcome to Python MUD Server documentation!¶

Задача: Разработка Multi-User Dungeon (MUD) с интеллектуальными монстрами и автоматизированной документацией

Цель:

Создать многопользовательскую текстовую RPG с распределённой архитектурой, реализующую:

  1. Динамическое перемещение монстров с обработкой столкновений

  2. Интерактивное взаимодействие игроков с окружением

  3. Полную техническую документацию системы

Серверная часть:

✔ Периодическое (30 сек) перемещение монстров на закольцованной карте 10x10

✔ Система коллизий: предотвращение наложения монстров

✔ Реакция на столкновения игроков с монстрами (энкаунтеры)

✔ Широковещательные уведомления о перемещениях на всех клиентов

Клиентская часть:

✔ Обработка ввода команд и взаимодействий

Документация:

✔ Автоматическая генерация API-документации через Sphinx + autodoc

✔ Титульная страница с описанием архитектуры и формулировкой задачи

✔ Ссылочная структура между концептуальным описанием и технической докой

Технические ограничения:

► Реализация на Python 3.12 с использованием asyncio

► Полное покрытие docstring для всех классов/методов

► Отдельная ветка git для разработки (work)

Ожидаемый результат:

◉ Работоспособный MUD-сервер с AI монстров

◉ HTML-документация с разделом “Технической документации”

◉ Набор юнит-тестов для критических компонентов

◉ .gitignore с исключением бинарников и генератов документации
